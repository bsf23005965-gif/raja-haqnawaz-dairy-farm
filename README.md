# Raja Haqnawaz Dairy Farm Management & Online Selling System

A production-style mobile application built with **React Native / JavaScript (JSX)**, **Zustand**, **Firebase architecture**, and **Google Gemini AI**. Suitable for a **BSCS Final Year Project (FYP)**, university evaluation, viva presentation, and commercial deployment.

---

## Highlights & Features

- **30+ Years Legacy:** Official branding honoring founder **Raja Haqnawaz** and his three decades of dairy breeding excellence.
- **Verified Contacts:**
  - **WhatsApp:** `0345 2923974` (Deep links pre-filled with animal inquiries and order verification)
  - **Phone:** `0300 6072070` (Direct farm phone line)
  - **Facebook & TikTok:** Official farm social media channels
- **Livestock Marketplace:** 32 verified Pakistani cattle records (Sahiwal, Nili-Ravi, Cholistani, Red Sindhi, Cross Breeds) with search, multi-factor filtering, and sorting.
- **Atomic Order Flow & Payment Simulator:** Simulates successful payments, failed payments, and Stripe checkout. Marks purchased animals as **SOLD** immediately to prevent double-selling.
- **AI Livestock Consultant:**
  1. *AI Chatbot:* Gemini-powered answers regarding breeds, feeding, vaccination, and care.
  2. *AI Health Checker:* Clinical symptom analyzer with mandatory medical disclaimer.
  3. *Smart Recommender:* Multi-factor weighted scoring algorithm (Price 30%, Breed 20%, Milk 25%, Age 10%, Health 10%, Availability 5%).
- **Interactive Farm Location:** Live coordinates on Google Maps with directions and visitor guidelines.
- **Full Admin Console:** Manage inventory, update cattle availability, review orders, update branding, and edit farm story content.
- **Mobile Device Simulator:** Toggle between an **iPhone 16 Pro shell** and **Full Screen** mode with quick screen jumping for viva presentations.

## Getting Started

```bash
# Install dependencies
npm install

# Run the development server (Express + Vite on Port 3000)
npm run dev

# Build for production
npm run build
```

The application runs on `http://localhost:3000`.
